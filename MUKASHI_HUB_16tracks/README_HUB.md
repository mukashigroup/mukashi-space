
MUKASHI Space HUB v3 - 16 tracks, пустая дорожка, до мастера.

Установка в Reaper:
1. Собери: cmake -B build && cmake --build build --config Release
2. Получишь 2 VST3:
   - MUKASHI Space HUB (16) -> вешаешь на ПУСТУЮ дорожку VISUAL MIX
   - MUKASHI Space SOURCE v2 -> вешаешь на каждый инструмент (Drums, Bass...)

Как работают вместе:
- Оба пишут в файл %TEMP%/mukashi_space_v3.json
- Таскаешь точку в HUB -> SOURCE на канале автоматом двигает панораму и глубину
- Таскаешь точку в SOURCE -> HUB видит изменение
- HUB показывает все 16 точек сразу. Можно переименовать (пока в коде массив names).

Фичи HUB:
- 16 точек, разные цвета
- Клик чтобы выбрать, драг чтобы двигать
- SHIFT+DRAG = лок оси (как просил)
- A/B/C/D: ALT+CLICK = SAVE всех 16 позиций, CLICK = RECALL
- Снапшоты сохраняются с проектом Reaper

Стерео-комната: без бинаурала, чистый стерео тракт.
